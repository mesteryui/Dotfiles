# i18n

Files: `en_US.json` (reference, always complete), `es_ES.json`,
`eo.json`. Same top-level sections in all three.

Conventions:

- Keys are dotted paths: `section.name`, e.g. `launcher.placeholder_all`,
  `settings.interface.bar.height`, `sysmenu.about_title`.
- Placeholders use `%1`, `%2` (battery, updates).
- `titleKey`/`subtitleKey` in launcher menus resolve through the same
  dictionary (see `Launcher/GUIA-MENUS.md` §6).
- QML call sites pass a Spanish inline default today;
  `I18nService.getTranslation(key, default)` now falls back per-key:
  loaded language → `en_US` → inline default. Still, keep `en_US`
  complete and add new keys there first.

Adding a locale:

1. Copy `en_US.json` to `<lang>.json` (use `Qt.locale().name` form,
   e.g. `fr_FR.json`).
2. Translate values, keep keys and `%1` placeholders.
3. `I18nService` normalizes `es_* → es_ES`, `en_* → en_US`;
   other languages load verbatim (`eo` → `eo.json`).
4. Missing file → whole-file fallback to `en_US`;
   missing key → per-key fallback to `en_US` value.
