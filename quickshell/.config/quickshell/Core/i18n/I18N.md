# i18n

Files: `en_US.json` (reference, always complete), `es_ES.json`,
`eo.json`. Same 16 top-level sections in all three (258 keys in
`en_US`): `battery`, `cheatsheet`, `launcher`, `lockscreen`,
`media`, `notifications`, `osd`, `panel`, `polkit`, `power`,
`settings`, `sysmenu`, `updates`, `wallpaper`, `weather`,
`switcher`.

Conventions:

- Keys are dotted paths: `section.name`, e.g. `launcher.placeholder_all`,
  `settings.interface.bar.height`, `sysmenu.about_title`.
- Placeholders use `%1`, `%2` (battery, updates).
- `titleKey`/`subtitleKey` in launcher menus resolve through the same
  dictionary (see `Launcher/GUIA-MENUS.md` §6).
- QML call sites pass a Spanish inline default;
  `I18nService.getTranslation(key, default)` resuelve `translations`
  → inline default, sin segundo fichero. Keep `en_US` complete and
  add new keys there first.

Language resolution (`I18nService`):

- `available`: códigos según los `*.json` presentes en `Core/i18n`
  (vía `FolderListModel`, se completa sola al añadir/quitar ficheros;
  `en_US` siempre presente como referencia).
- `configs.language` (`userDefinedLang`): `"auto"` (o vacío) usa
  `Qt.locale().name` solo si está en `available`, si no `en_US`.
  Valor manual solo si está en `available`, si no `en_US`.
- Sin alias por familia: solo se normaliza `"-"` a `"_"` por formato
  (`"es-ES"` → `"es_ES"`). `"es"` o `"es_MX"` sin fichero → `en_US`.
- Loader: un solo `FileView` candidato (`candidatePath` ya validado:
  fuera de lista => `en_US`). `watchChanges: true` para recarga en vivo.
- Missing file → se vacía y `language` pasa a `en_US` (console warns);
  al actualizarse `available` se recarga solo. Missing key →
  `translations` → default inline.

Adding a locale:

1. Copy `en_US.json` to `<lang>.json` (use `Qt.locale().name` form,
   e.g. `fr_FR.json`). Aparece solo en `available` y en el desplegable
   de idioma (más `Auto`).
2. Translate values, keep keys and `%1` placeholders.
3. No hay que tocar `candidateLang`: sin alias que mantener.
4. Opcional: añadir nombre en `I18nService.languageName()` para el
   desplegable; si no, se muestra el código tal cual.
