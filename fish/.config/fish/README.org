* Configuración de la shell
** Definiendo valores importantes
Aqui defino algunos valores sobre que nos servirán para luego
*** Definiendo el PATH
Aquí defino los directorios del path
#+name: PATH
#+begin_src fish :tangle no 
~/.cargo/bin ~/.local/bin ~/ /usr/local/bin ~/.local/share/pipx/venvs
#+end_src
*** Definiendo valores de TERM
#+name: TERM
#+begin_src fish :tangle no
"xterm-256color"
#+end_src
*** Definiendo editor tanto grafico como por comando
**** Visual
#+name: VISUAL
#+begin_src fish :tangle no
"emacsclient -c -a emacs"
#+end_src
**** EDITOR
#+name: EDITOR
#+begin_src fish :tangle no
"emacsclient -t -a ''"
#+end_src
** Definiendo si el estado es el interactivo cosas que se añaden
*** Zoxide
Añadiendo zoxide una herramienta que es como cd pero con superpoderes, es bastante chulo
#+name: zoxide
#+begin_src fish :tangle no
zoxide init fish | source
#+end_src
*** Starship
Es un sustituto al prompt normal el cual permite lograr grandes resultados para customizar el prompt
lo chulo es que es asiduo a la shell que uses
#+name: prompt
#+begin_src fish :tangle no
starship init fish | source
#+end_src
*** The fuck
Nos permite escribiendo =fuck= te da una corrección al ultimo comando y te da la opción de usarla siendo muy útil para corregir tus errores
puedes añadir errores frecuentes
#+name: thefuck
#+begin_src fish :tangle no
thefuck --alias | source
#+end_src
*** Aplicar configuracion 
#+begin_src fish :noweb yes 
if status is-interactive
    # Commands to run in interactive sessions can go here
    set -g fish_greeting
    #set -x MANPAGER "nvim +Man!"
    set -g TERM kitty
    # starship
    <<prompt>>
    # atuin
    atuin init fish | source
    # zoxide
    <<zoxide>>
    <<thefuck>>
    #syncthing
    #syncthing install-completions | source
    fzf --fish | source
    # Television
    #tv init fish | source
end
#+end_src

** Seteando variables
Aqui seteamos en la shell diversas variables necesarias para poder hacer el trabajo
*** Seteando PATH
#+begin_src fish :noweb yes
set -U fish_user_paths -g <<PATH>>
#+end_src
*** Seteando variables diversas
Aquí declaramos variables diversas que nos servirán a posteriori
#+begin_src fish :noweb yes
set VISUAL <<VISUAL>>
set EDITOR <<EDITOR>>
set -x PASSWORD_STORE_DIR '/home/oscar/.local/share/pass'
set -x NNTPSERVER 'snews://news.eternal-september.org'
#+end_src
